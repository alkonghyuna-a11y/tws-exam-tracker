# tws-exam-tracker

투자자산운용사(투운사) 모의고사 회독 관리 앱.

문제집은 종이로 보고, 답만 터치로 입력해 자동 채점하고, 같은 시험을 여러 번 풀며 어느 세부과목에서 반복해서 틀리는지 추적합니다.

## 바로 쓰기

GitHub Pages 주소로 접속하면 설치 없이 바로 실행됩니다.
휴대폰 브라우저에서 열고 "홈 화면에 추가"를 하면 앱처럼 쓸 수 있습니다.

## 기능

- 시험 이름 직접 등록 (모의고사·기출유형 개수 제한 없음)
- 정답표 100문항 등록 (하나씩 터치, 또는 번호 문자열 한 번에 붙여넣기)
- 1~100번 4지선다 터치 입력 → 채점 버튼 한 번으로 일괄 채점
- 회독 차수 자동 누적, 회독별 점수 추이
- 과목별 정답률과 과락선(1과목 8 / 2과목 12 / 3과목 20) 대비 표시
- 세부과목 16개 누적 정답률, 낮은 순 정렬
- 문항별 O·X 이력과 상태 분류 (완전 미해결 / 방심 오답 / 불안정 / 안정)
- 분석용 요약 텍스트 및 문항표 CSV 내보내기

## 문항 매핑 기준

한국금융투자협회 투운사 세부과목 구성표(100문항) 기준입니다.

| 과목 | 문항 | 과락 |
|---|---|---|
| 1과목 금융상품 및 세제 | 1~20 | 8문항 |
| 2과목 투자운용 및 전략Ⅱ 및 투자분석 | 21~50 | 12문항 |
| 3과목 직무윤리 및 법규/투자운용 및 전략Ⅰ 등 | 51~100 | 20문항 |

세부과목 구간은 `index.html` 안의 `SECTIONS` 값에 정의되어 있습니다.
문제집에 따라 문항 배열이 다르면 이 값만 고치면 됩니다.

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 본체. 이 파일 하나로 실행됩니다 |
| `manifest.json` | 홈 화면 추가 설정 |
| `앱아이콘_*.png`, `파비콘_시험지.svg` | 아이콘 |
| `투운사_회독관리앱.jsx` | 원본 React 소스 (수정용) |

## 기록 저장 위치

기록은 접속한 기기의 브라우저 저장소에 남습니다. 서버로 전송되지 않습니다.
기기나 브라우저를 바꾸면 기록이 따라오지 않으므로, 중요한 기록은 통계 화면의 **자료 내보내기**로 백업해 두십시오.
